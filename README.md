# Lucid Cyber RPG - Collective World State

This repository contains the **living, breathing narrative** of Lucid Cyber RPG.

## What is This?

Every player's choice in Lucid Cyber RPG creates a **real git commit** to this repository.
The collective story emerges through automatic karma-based merging.

## Structure

```
branches/
  main/           - Merged collective narrative
  cohorts/
    light/        - Players with positive karma
    balanced/     - Neutral karma players
    shadow/       - Negative karma players
  players/        - Individual player branches
```

## How It Works

1. Player makes choice in game
2. Commit created: `[PlayerName] ChoiceText (Karma: +/-X)`
3. If karma aligns (±3 points), branches auto-merge
4. Merged narrative visible to all

## Karma Cohorts

- **Light Walkers** (+50+) - Altruistic, constructive choices
- **Balanced Seekers** (±10) - Pragmatic, neutral paths
- **Shadow Embracers** (-50-) - Dark, destructive paths
